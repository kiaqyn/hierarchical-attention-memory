# 通用编程代理记忆题库 v1.0

200 题，覆盖 140 个语义或操作任务。这里交付的是题目、合成历史、标准答案、评分规范及数据工具；没有运行任何参评系统，没有新的胜负或省额度结论。

- 日常主测 120 题：60 个语义任务，各有中英文版本。包含 20 类任务，每类 6 题。
- 语言和格式附测 32 题：短词、多文字体系、Unicode、符号路径、单位、否定和协议形态。
- 故障与维护 32 题：事务、并发、损坏、缓存失效、平台、服务、导出迁移和保留策略。
- 成本和长期使用 16 题：预算、重复查询、100～10000 条记录、20～1000 个事件回合。

主测中的 72 题覆盖通用能力，24 题侧重范围/约束/受控保存，24 题侧重自动观察/工作流程/跨会话延续。后两类分别覆盖 HFA 和 Claude-Mem 所关注的设计方向，不预设哪一方获胜。主测中英各 60 题；翻译版本不冒充独立样本。

开放场景无法穷尽。本版覆盖本次列出的 40 类场景，不声称涵盖所有任务，也不是第三方独立或未见测试集。题目公开后可用于开发回归；检验泛化还需另行冻结、未被双方调参使用的外部样本。

本版聚焦文本型编程代理记忆。视觉/音频理解、企业多租户鉴权、硬件断电可靠性与线上用户规模需要独立场景；本题库也不能单独证明真实代码修复任务的最终成功率。

## 从哪里看

- question-book.md：全部题目、给定记录、操作、标准答案与检查项，直接阅读。
- cases.jsonl：问题、范围、模式与预算；不包含标准答案。
- scenarios.json：纯合成历史和双方相同的结构化记录。
- answer-key.json：标准答案、证据组与独立观察要求。不要交给参评代理。
- protocol.md：模式、计分、双方适配边界、成本口径。
- coverage.json：题数、分组与设计覆盖。
- materialize.py：输出仅供参评代理读取的公共输入；不调用引擎或模型。
- grade.py：标准化答案和独立观察的确定性判分，不是自然语言万能裁判。
- validate.py：校验题库、引用、覆盖和判分反例；不代表参评系统通过。
- freeze-manifest.json：最终文件指纹；任何题目、答案或评分逻辑变更需要新版本。

## 使用

需要 Python 3.10+，工具仅用标准库。先校验题库：

    python -B validate.py

生成一题公开输入到全新目录：

    python -B materialize.py --case M01-01-zh --mode records --out ./public-run-001

native 模式给双方原始历史，不提供人为提炼的记录；records 模式给双方同样的已提炼记录。两种结果分开统计，不能用对方的精简路径对阵自己的全功能链路，再宣称产品整体领先。

判分需要实际运行产生的 response.json 和独立观察 observations.json；本题库没有伪造这些文件：

    python -B grade.py --case M01-01-zh --mode native --response ./run/response.json --observations ./run/observations.json

没有独立证据时返回 pending_evidence，不冒充通过。这里没有参评适配器或自动执行器；故障注入、宿主操作、后台观察器与服务端实现需要各自适配后才能实测。
